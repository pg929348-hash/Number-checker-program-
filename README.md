
# 🔢 Number Checker Program 🧐

A simple Python program to check whether a number is greater than 10 or not.

This program uses a list and a for loop!

## 🌟 Features
- 📋 Stores numbers in a list
- 🔁 Loops through each number using `for loop`
- ✅ Checks if number is greater than 10
- 🖨️ Prints result with f-string

## 🧠 How It Works
1.  A list is created: `n = [12,5,8,19,22,3,14]`
2.  `for i in n:` picks each number one by one
3.  `if i > 10:` checks the condition
4.  If true -> prints `yes, {i} is greater than 10`
5.  If false -> prints `no, {i} is less than 10'
